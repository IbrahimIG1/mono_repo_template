# minimal_app

The smallest executable reference for the admitted V2 foundation. It demonstrates an app-owned composition root, constructor injection, lifecycle disposal, typed persistent state, networking configuration, and the brand-neutral design system.

It deliberately contains no Firebase, auth, routing framework, realtime, socket, chat, `core`, `shared`, or service locator dependency.

Run from this directory with `flutter run`, or build Android, iOS, Web, and Windows using the commands in the Goal 3 migration record.
