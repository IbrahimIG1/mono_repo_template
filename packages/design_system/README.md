# design_system

Brand-neutral Material 3 theme construction, spacing tokens, and reusable presentation primitives.

Use `PlatformTheme.light` / `PlatformTheme.dark`, the `AppSpacing` theme extension, and `StatusCard`. Apps provide the seed color and own product fonts, assets, copy, localization, and final branding. This package must not depend on networking, storage, app code, or legacy packages.
